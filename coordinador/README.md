# Coordinador

```
python coordinador\coordinador_provisional.py   coordinador PROVISIONAL (lo arranca iniciar.bat)
python coordinador\pruebas_coordinador.py       prueba sus reglas con datos inventados
```

`coordinador_provisional.py` junta los datos de una sesión de la estación (reacción, símbolos, cuestionario,
voz y visión) y publica el semáforo con `"provisional": true`. Sus reglas están al inicio del archivo y en la
sección 6 del README principal, junto con los pasos para que Danilo lo reemplace por `coordinador.py`.
